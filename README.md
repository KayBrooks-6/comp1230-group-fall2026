# Study Group Finder (COMP1230 Group Project)

Welcome to the repository for our **Study Group Finder** web application, built for COMP1230 Advanced Web Programming at George Brown College. This project is a dynamic PHP and MySQL website that allows students to register, log in, create study groups, and browse or manage sessions together.

---

## Project Overview

This website is built in three main phases to help students easily find and coordinate study sessions:

- **Phase 1 (Current):** Sets up core database connections (PDO), user authentication (registration, login/logout), and full group creation, editing, and deletion features.
- **Phase 2:** Adds group membership features (joining and leaving groups) along with enhanced security rules like owner-only permissions and CSRF protection.
- **Phase 3:** Reorganizes the project code structure, adds data export tools (CSV/JSON), sets up error handling, and prepares the final deployment.
